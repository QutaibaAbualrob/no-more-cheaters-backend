# Agent history / task logs

This folder stores **session notes** for work done with the AI assistant: plans, steps taken, command output, errors, and outcomes.

## Convention

- One file per task or per day is fine; use whatever naming helps you find things (e.g. `2026-03-29_scaffold-backend.md`, `task-upload-api.md`).
- Include when useful:
  - **Goal** — what you asked for
  - **Plan** — high-level approach
  - **Steps** — ordered list of what was done (files touched, commands run)
  - **Errors / logs** — copy-paste of tracebacks, failed commands, stderr
  - **Resolution** — how errors were fixed or what is still blocked
  - **Follow-ups** — optional next steps

## Note

The assistant will append or create files here when you request tasks on this project, unless you say otherwise.
